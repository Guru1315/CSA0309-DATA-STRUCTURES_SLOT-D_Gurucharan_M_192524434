## Questions answered

**Q1: Smart healthcare system.** A concept map linking *Data → Data Object → Data Structure → Abstract Data Type (ADT) → Implementation in C*, with structures, pointers and operations as sub-concepts. The written justification covers:

- **Data:** raw facts such as a temperature value, patient identifier or blood-pressure reading
- **Data object:** a meaningful group of related data, for example a patient record
- **Data structure:** an organized way to store data for efficient access, insertion, deletion, search and update (arrays and linked lists for patient records)
- **ADT:** what operations are supported, separate from how they are implemented
- **Implementation in C:** `struct`, pointers, arrays, dynamic memory and functions
- **Structures, pointers, operations:** grouping mixed attributes, building dynamic structures such as linked lists, and the create / insert / delete / search / access / update operations

**Q2: Smart city traffic management.** A concept map connecting *Primitive → Non-Primitive → Linear → Non-Linear* data structures, with traffic examples:

| Category | Structure | Traffic use given in the answer |
|---|---|---|
| Primitive | `int`, `char`, `float`, `double` | Vehicle counts, signal timings, identifiers, measured speeds |
| Linear | Array | Vehicle records for a defined road segment, with direct indexed access |
| Linear | Linked list | Active vehicles whose number changes often, with no contiguous memory needed |
| Non-linear | Tree | Road hierarchies, zones, and intersections grouped by region |
| Non-linear | Graph | Road network, with intersections as vertices and roads as edges, used for traversal and shortest-path analysis |
